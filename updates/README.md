# تحديثات مفكرتي (للتوزيع فقط)

هذا المجلد مخصّص لملف `update.json` الذي يقرأه التطبيق للتحقق من وجود إصدار أحدث.

- لا تحتاج لجعل **شيفرة المصدر** عامة من أجل التحديث.
- يكفي أن يكون رابط `update.json` ورابط الـ APK قابلين للتنزيل علناً (مثلاً Firebase Hosting أو GitHub Release عام).

راجع `update.json` في هذا المجلد و`web/update.json` للنشر على الاستضافة.
