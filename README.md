# ملاحظاتي الذكية

تطبيق مذكرات عربي — **v1.0.1**

## الميزات

- مذكرات غنية مع محرر Quill
- مزامنة Firebase مع تشفير المحتوى والوسوم
- قوالب، تذكيرات، نسخ احتياطي، ويدجت
- إعلانات App Open و Exit فقط (بدون بانر)

## التطوير

```bash
flutter pub get
flutter run
```
