# مفكرتي

تطبيق مذكرات عربي — **v1.0.2**

## الميزات

- مذكرات غنية مع محرر Quill
- مزامنة Firebase مع تشفير المحتوى والوسوم
- خطوط عربية متعددة مع معاينة
- قوالب، تذكيرات، نسخ احتياطي، ويدجت
- إعلانات App Open و Exit فقط (بدون بانر)

## التطوير

```bash
flutter pub get
flutter run
```

## الإصدارات

- **1.0.2** — إعادة تسمية التطبيق إلى مفكرتي، تحسين الفوتر وزر الإضافة، خطوط عربية، حجم خط بالأرقام، إصلاح التصدير المشفر، سحب للمزامنة
- **1.0.1** — إصلاح overflow، إزالة البانر، تشفير الوسوم، إعلان الإغلاق، صلاحية المذكرة العائمة
